## 👋 About

I build full-stack product features at **Fiscozen**, mostly with **Django** and **Vue.js**.

Outside work I contribute to open source across Node.js, Python and C — from web frameworks
to local LLM inference.

## 🧪 Projects

**[recsyslearn](https://github.com/giuliowaitforitdavide/recsyslearn)** — Python library for evaluating recommender systems:
accuracy (NDCG), beyond-accuracy (coverage, novelty) and group fairness (entropy, KL divergence, mutual information),
with built-in user/item segmentations. Available on [PyPI](https://pypi.org/project/recsyslearn/).
Feature-complete and in maintenance mode — kept compatible with the latest pandas/numpy.
